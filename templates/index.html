AI-Enabled Mine Monitoring System

Real-Time Sensor Monitoring and Machine Learning Based Risk Detection

The system uses multiple IoT sensors connected to an ESP32 receiver to monitor underground environmental and structural conditions. Sensor telemetry is transmitted to a central backend web server, where it is displayed in real time and evaluated using a Random Forest Machine Learning model to identify potential hazard conditions.

3. Receiver Wi-Fi / Gateway

5. ML Analysis Random Forest
6. Dashboard Real-Time Graphs
7. Alert Risk Mitigation

MPU6050 Structural Tilt

Monitors ground shift, slope tilt angle, and 3-axis accelerometer/gyroscope movement to catch pre-collapse structural movement.

Seismic & Vibration Sensing

Tracks high-frequency rock movement, micro-seismic vibrations, and cumulative shock event counts to detect subterranean instability.

DHT Temperature & Humidity

Supports both DHT11 and DHT22 environmental sensors to measure ventilation health, humidity build-up, and thermal anomalies.

ESP32 Receiver Connection Instructions

Step-by-step guide to flash your ESP32 hardware and send real sensor readings.

1. Backend API Specification

SERVER_URL: /api/sensor-data
HTTP Method: POST
Content-Type Header: application/json

2. Expected JSON Format

{
  "node_id": "NODE_01",
  "tilt": 7.4,
  "accel_x": 0.12,
  "accel_y": 0.45,
  "accel_z": 9.72,
  "gyro_x": 1.2,
  "gyro_y": 0.8,
  "gyro_z": 0.4,
  "vibration": 42,
  "temperature": 29.5,
  "humidity": 64
}

3. Complete Arduino ESP32 C++ Code

Copy and paste this sketch into Arduino IDE. Replace WIFI_SSID, WIFI_PASSWORD, and SERVER_URL. 

#include <WiFi.h>
#include <HTTPClient.h>
#include <ArduinoJson.h>

const char* ssid = "YOUR_WIFI_SSID";
const char* password = "YOUR_WIFI_PASSWORD";
const char* serverUrl = "http://YOUR_SERVER_IP:3000/api/sensor-data"; // Change to your server URL

const char* nodeId = "NODE_01";
unsigned long sendInterval = 3000; // 3 seconds
unsigned long lastSendTime = 0;

void setup() {
  Serial.begin(115200);
  WiFi.begin(ssid, password);
  Serial.print("Connecting to Wi-Fi");
  while (WiFi.status() != WL_CONNECTED) {
    delay(500);
    Serial.print(".");
  }
  Serial.println("\nConnected to Wi-Fi!");
}

void loop() {
  if (millis() - lastSendTime >= sendInterval) {
    lastSendTime = millis();
    if (WiFi.status() == WL_CONNECTED) {
      HTTPClient http;
      http.begin(serverUrl);
      http.addHeader("Content-Type", "application/json");

      // Replace dummy values below with real MPU6050, Vibration & DHT readings
      StaticJsonDocument<256> doc;
      doc["node_id"] = nodeId;
      doc["tilt"] = 2.4; 
      doc["accel_x"] = 0.05; doc["accel_y"] = 0.10; doc["accel_z"] = 9.80;
      doc["gyro_x"] = 0.10; doc["gyro_y"] = 0.00; doc["gyro_z"] = -0.05;
      doc["vibration"] = 12;
      doc["temperature"] = 28.5;
      doc["humidity"] = 54.0;

      String requestBody;
      serializeJson(doc, requestBody);

      int httpResponseCode = http.POST(requestBody);
      if (httpResponseCode > 0) {
        String response = http.getString();
        Serial.println("Response code: " + String(httpResponseCode));
        Serial.println("Response: " + response);
      } else {
        Serial.println("Error on POST: " + String(httpResponseCode));
      }
      http.end();
    }
  }
}
